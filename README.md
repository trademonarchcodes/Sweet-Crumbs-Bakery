# Sweet Crumbs Bakery

A responsive bakery website for Sweet Crumbs Bakery, Port Harcourt, Nigeria.

## Features
- Responsive mobile, tablet and desktop layout
- Bakery menu and product showcase
- WhatsApp enquiry and ordering links
- Customer feedback invitation (real testimonials can be added when supplied)
- Port Harcourt map embed and contact details
- Mr. Chef mascot artwork
- DEVLYON development credit

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/images/mascot/` — Mr. Chef image assets

## Before launch
Confirm the bakery's real product list, prices, exact street address, and approved customer reviews. Current menu links ask customers to request the latest prices rather than displaying unconfirmed prices.

## Deployment
Deploy with Cloudflare Pages using the `main` branch and repository root as the build output directory. No build command is required.

Cloudflare Pages project: https://sweet-crumbs-bakery.pages.dev
